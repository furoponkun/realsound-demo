# Real Sound: The Winds of Regret — subtitled audiobook

**▶ [Listen to It](https://furoponkun.github.io/realsound-demo/)**

A web player for the 2024 audiobook edition of *Real Sound: Kaze no Regret*
(WARP, Sega Saturn, 1997), with English subtitles synchronized to the Japanese audio
and shown in an RPG-style dialogue box.
